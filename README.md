# Early Dropout Risk Detection Using Language & Behavior

AI-powered student dropout risk prediction system using NLP, XGBoost, and behavioral analytics to identify at-risk students and support early intervention strategies.


## Project Overview

Student dropout remains a significant challenge for educational institutions worldwide. Identifying at-risk students early enables institutions to provide timely support, improve retention, and enhance academic outcomes.

This project develops an AI-powered early warning system capable of identifying students at risk of dropping out using academic, behavioral, and linguistic indicators. The system combines Natural Language Processing (NLP) and Machine Learning techniques to generate actionable insights for intervention planning.


## Problem Statement

Educational institutions often identify struggling students only after their academic performance has significantly declined. This delay reduces the effectiveness of intervention strategies.

The objective of this project is to predict dropout risk before students leave the institution by analyzing behavioral patterns, engagement metrics, academic performance, and language-based signals.


## Dataset

A synthetic dataset was designed and generated to simulate realistic student records and educational scenarios.

### Features Included

- Attendance Rate
- Assignment Completion Rate
- Academic Performance
- Participation Score

- Behavioral Indicators
- Student Feedback Text
